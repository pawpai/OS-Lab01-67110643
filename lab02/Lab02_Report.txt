1. Execution Time Comparison:
- Sequential Time: 9.12 seconds 
- Multithreading Time: 8.71 seconds 
- Multiprocessing Time: 8.27 seconds

2. System Observation (htop):
Multithreading ใช้ CPU แค่ core เดียว เพราะ GIL ทำให้ Python รันได้ทีละ thread ส่วน Multiprocessing ใช้ ทั้ง 2 cores พร้อมกัน 
เพราะแต่ละ process มี GIL แยกกัน ทำให้ OS กระจายงานไปแต่ละ core ได้จริง

3. Analysis (The GIL):
Multithreading ไม่ช่วยให้งาน CPU-bound เร็วขึ้น เพราะ GIL อนุญาตให้รัน Python bytecode ได้ทีละ thread เท่านั้น 
ส่วน Multiprocessing แยก interpreter และ GIL ของแต่ละ process จึงสามารถใช้หลาย cores พร้อมกันได้
