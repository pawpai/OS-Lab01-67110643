1. Execution Time Comparison:
- Sequential Time: 9.12 seconds 
- Multithreading Time: 8.71 seconds 
- Multiprocessing Time: 8.27 seconds

2. System Observation (htop):
Multithreading ใช้แค่ core เดียว (สลับไปมา) เพราะ GIL บังคับให้รันทีละ thread 
ส่วน Multiprocessing ใช้ทั้ง 2 core พร้อมกันเต็มที่ เพราะแต่ละ process มี GIL 
ของตัวเอง OS เลยกระจายงานไปคนละ core ได้จริง

3. Analysis (The GIL):
Multithreading ไม่เร็วขึ้นเพราะ GIL อนุญาตให้รัน Python bytecode ได้ทีละ thread 
เท่านั้น ไม่ว่าจะมีกี่ core ก็ตาม งานแบบ CPU-bound (คำนวณหนัก) จึงไม่ได้ประโยชน์
จาก threading เลย ตรงข้ามกับ Multiprocessing ที่แต่ละ process แยก interpreter/GIL 
กัน ทำให้ OS กระจายไปรันบนหลาย core พร้อมกันได้จริง เหมาะกับงาน ML data 
augmentation ที่เป็นงานคำนวณหนักแบบนี้
