1. The Deadlock (Phase 2):
Model A ได้ GPU 0, Model B ได้ GPU 1 พร้อมกัน จากนั้นทั้งคู่ขอทรัพยากรที่อีกฝ่าย
ถืออยู่ (A ขอ GPU 1, B ขอ GPU 0) ทำให้ต่างฝ่ายต่างรอกันไปมาไม่มีใครยอมปล่อยก่อน 
เกิด Circular Wait และค้างสนิท (ต้องกด Ctrl+C)

2. The Solution (Phase 3):
บังคับให้ B ขอ GPU 0 ก่อนเหมือน A ทำให้มีแค่ฝ่ายเดียวที่ถือ GPU 0 ได้ก่อนเสมอ 
อีกฝ่ายแค่รอเฉย ๆ โดยยังไม่ถืออะไร จึงไม่เกิด Circular Wait โปรแกรมรันจบปกติ

3. Starvation vs Deadlock (Phase 4):
ผลจริง: Greedy_A 23415 ครั้ง, Greedy_B 23466 ครั้ง, Polite 297 ครั้ง 
ต่างจาก Deadlock ตรงที่ระบบไม่ค้าง ยังทำงานได้ปกติ แค่ Polite ได้ทรัพยากรน้อย
กว่ามาก (~158 เท่า) ไม่เป็นธรรม แก้ด้วย Aging คือค่อย ๆ เพิ่ม priority ให้ 
thread ที่รอนาน จนสุดท้ายได้คิวแน่นอน

4. Deadlock Detection & Recovery (Phase 3.3):
timeout=2 วินาทีทำหน้าที่แทนกลไกตรวจจับของ OS แทนที่จะรอตลอดไป พอรอเกิน 2 วิ 
ระบบถือว่าเป็น Deadlock แล้วให้ Model A ปล่อย GPU 0 คืน (Recovery) ทำให้ 
Model B ได้ทรัพยากรไปทำงานต่อจนจบ ระบบไม่ค้างทั้งหมด
